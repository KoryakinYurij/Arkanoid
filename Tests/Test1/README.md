# SIDE EFFECT

Откройте **Side Effect.html** двойным щелчком. Установка и интернет для игры не нужны.

Поле сохраняет исходные вертикальные пропорции 540×960. По бокам показаны арсенал, улучшения и прогресс слияний; на узком экране они доступны через «Пауза → Сборка».

## Управление

- Мышь, стрелки или A/D — двигать платформу.
- Пробел или щелчок — залп; когда останется не больше половины шаров, повторное нажатие возвращает их.
- Shift или экранная кнопка — удерживать замедление времени.
- P / Esc — пауза. R — новая попытка. M — звук.
- На сенсорном экране — вести пальцем по полю; замедление можно удерживать вторым пальцем.
- 1 / 2 / 3 — выбрать улучшение.

Все стихии, слияния, пассивные улучшения и правила описаны в игровом меню «Как играть». Рекорды и настройки сохраняются в браузере на этом устройстве.

## Мастерская и открытия

«Мастерская» доступна из главного меню, паузы и результата. Альбом сохраняет найденные слияния между попытками; боковые панели показывают только текущий забег.

- Первый побеждённый босс открывает «Пиротехника»: три обычных шара и один огненный.
- Первое слияние открывает «Криолога»: три обычных шара и один ледяной.
- Десять идеальных отбиваний за один забег открывают один переброс карточек в каждой следующей попытке.
- Все четыре найденных слияния дают отметку «Мастер синтеза».

Классический старт — пять обычных шаров. Выбранная сборка применяется и при рестарте клавишей R. Улучшения забега сбрасываются; альбом и достижения сохраняются сразу. В рекордах указаны стартовый набор и использованный переброс.

Прогресс хранится локально в этом браузере. Очистка данных браузера удаляет сохранение.

## Что объединено

Вся игровая механика — из `arkanoid-great-mechanic.zip`. Бумажная палитра, геометричные кирпичи, зерно, обломки, отдача и характер звука — из `Great visual and feel of game.html`. Вместо вида веб-страницы — игровое пространство с отдельным главным меню, вертикальным полем и полезной информацией по бокам. Поле масштабируется с сохранением пропорций.

## Исходники и проверка

Из этой папки: `npm ci`, затем `npm run dev`. Сборка: `npm run build` — обновляет `dist/index.html` и `Side Effect.html`. Проверка типов: `npm run check`. Регрессии механики: `npm test` (Node.js 22.13+).

Снимки и отчёт браузерной проверки находятся в `output/playwright`. Описание решений — в `docs`.
