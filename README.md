# Arkanoid Prototypes & Experiments

A collection of game design explorations, reference mechanics, and prototypes evolving classic brick-breaker / Arkanoid gameplay with modern tactile mechanics, upgrades, and styling.

## Repository Structure

- **`Projects for Destill/`**: Reference materials and design distillations.
  - `arkanoid-great-mechanic.zip` ("Neon Pit"): Ball kinds, fusion recipes, passive upgrades, XP card drafting, combo systems, descending wall, boss rows.
  - `Great visual and feel of game.html` ("Side Effect"): Paper-and-ink editorial styling, letterpress typography, clip-path print blocks, hit-stop, and trauma shake.
- **`Tests/Test1/` (Side Effect)**:
  - Vertical-layout paper-and-ink brick breaker.
  - Built with Vite, React, TypeScript, and Tailwind CSS.
  - Standalone build available as `Side Effect.html`.
- **`Tests/Test2/`**:
  - React + Vite + Tailwind prototype.
- **`Tests/Test3/` (Under Pressure)**:
  - Fusion-fuelled brick breaker synthesising the deep fusion mechanics from "Neon Pit" with the paper-and-ink editorial art direction of "Side Effect".
